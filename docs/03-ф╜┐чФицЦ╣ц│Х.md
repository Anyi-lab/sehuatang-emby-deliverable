# 03 · 使用方法

## 一、油猴脚本（浏览器端）

### 1.1 安装

1. 浏览器安装 Tampermonkey（油猴）插件
2. 打开油猴管理面板 → 「实用工具」→「导入」→ 选择 `src/userscript/sehuatang_import.user.js`
3. 编辑脚本，修改头部配置：

```javascript
// ===== 可配置 =====
const API_BASE = 'http://<SERVER_IP>:5081';   // ← 改成你的 import-api 地址
const POLL_MS = 6000;                          // 任务状态轮询间隔（毫秒）
// ==================
```

4. 保存并启用。

> 脚本 `@match` 已覆盖 `sehuatang.net` / `sehuatang.org` 的 http/https。

### 1.2 在帖子页入库

打开色花堂任意帖子页，页面右下角出现**磁力导航面板**：

| 控件 | 功能 |
|---|---|
| 每个链接按钮 🚀 | 单条入库：弹出入库类型选择（已入库/排队中的链接会直接提示，不再重复提交） |
| 类型选择「影片」 | 番号类单部电影：推→等→清小文件→strm→MDC 刮削→Emby 刷新→预热 |
| 类型选择「剧集」 | 非番号合集/剧集：推→等→重命名 thread_xxx_S01E01→strm→油猴补充元数据 |
| ⚡ 批量入库 | 一次提交本页全部（或勾选）磁力/ed2k：默认类型整批共用，行内可单独改成「番/剧」，先 👁 预览再 🚀 提交，进度显示在面板头部徽章（v1.11.0） |
| ✏️ 手动输入 | 手动输入磁力/ed2k 链接入库（支持多条，提交到当前 thread） |
| 📤 元数据补充 | 从帖子页提取标题/简介/图片，上传服务器生成 Emby 海报与简介 |
| 📋 任务监控页 | 一键跳转 `/tasks` 状态页 |

### 1.3 批量入库（⚡，v1.11.0）

帖子页磁力动辄几十条，逐条点效率太低。点面板头部 **⚡** 打开批量面板：

1. **（可选）调类型**：顶部「默认类型」番号/非番号整批共用；个别链接要单独走另一种，点该行右侧的「番/剧」即可
2. **（可选）调分类**：顶部下拉选刮削分类（AV/FC2/丝袜/国产自拍/欧美/里番，会记住上次选择）；也可在粘贴的链接行尾写 `#分类key` 单独覆盖
3. **勾选**：默认全选；已提交过的行默认不勾选。快捷键：全选 / 全不选 / 反选 / 仅未提交
4. **👁 预览**：只做校验不建任务，先把无效行、重复行挑出来
5. **🚀 批量入库**：按类型分批提交（单批上限 100 条，超了自动切开），服务端逐条建任务并按队列执行

提交后**可以关掉面板继续浏览**：进度显示在面板头部 `⚡完成/总数` 徽章上，导航列表框内对应链接尾部显示 🕒（进行中）/ ✅（已入库）/ ❌（失败），鼠标悬停可看 task_id。超过 100 条时前端按类型自动分批提交，无需手工切。

> 批量入口只是把「逐条点 🚀」换成一次提交，落点、剧集模式、元数据目录与单条入库**完全一致**（同一个 `thread_<tid>`）。

### 1.4 元数据补充（📤）

- 抓取帖子标题、简介、图片（仅静态 jpg/png/webp/gif，排除小图标/表情包）
- **图片为用户手工点选**：候选图网格最多选 9 张，可 📌 标记海报、↑↓ 调整顺序、✕ 移除
- 上传保留原格式（gif 传 .gif、png 传 .png），自动生成 `poster.jpg` / `fanart.jpg` / `backdrop1.jpg`… 并触发 Emby 刷新 + 预热
- 标题清洗：自动去掉发布者/来源前缀、体积配额后缀、分区论坛后缀（不影响入库原始标题，面板中可手动编辑）

### 1.5 注意事项

- **剧集任务需等 `/tasks` 状态变为 `done`**（strm 阶段完成）后再点 📤 上传；仍在 wait/下载/整理中上传会失败
- 影片任务如果 MDC 刮削失败或元数据不完整，任务会提示「请在帖子页用油猴脚本补充元数据」

## 二、任务监控页（服务器端）

访问 `http://<SERVER_IP>:5081/tasks`：

| 功能 | 说明 |
|---|---|
| 任务列表 | 状态（queued/wait/video/strm/done/failed）+ 步骤 + 进度 |
| 详情 | 点击查看任务时间线、错误信息 |
| 🎬 MDC 重跑 | 影片任务一键重跑（rescrape）：从 115 源文件重建 strm + 刮削（含影片重命名环节） |
| #tid 跳转 | thread 号可点击，直达帖子页做油猴补充 |

## 三、入库 API 说明

所有接口返回 JSON。

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/import` | POST | 提交单条入库 `{thread_id, title, magnet/ed2k, kind, thread_url}` |
| `/api/import/batch` | POST | 批量入库 `{links: [..] 或 "一行一条", kind, category, thread_id, title, thread_url, dry_run}`（单批 ≤100 条） |
| `/api/import/list` | GET | 任务列表（分页） |
| `/api/import/status` | GET | 任务状态 `?task_id=` |
| `/api/import/history` | GET | 任务时间线 |
| `/api/import/rescrape` | POST | MDC 重跑 `{thread_id, kind:"mdc"}` |
| `/api/metadata` | POST | 元数据补充（nfo/图片写入 + Emby 刷新） |
| `/health` | GET | 健康检查 |

### 示例：提交入库

```bash
curl -X POST http://<SERVER_IP>:5081/api/import \
  -H 'Content-Type: application/json' \
  -d '{
    "thread_id": "1234567",
    "title": "【原档】示例标题",
    "magnet": "magnet:?xt=urn:btih:xxxxxxxx",
    "kind": "fanhao",
    "thread_url": "https://sehuatang.net/thread-1234567-1-1.html"
  }'
```

### 示例：批量入库（面板 ⚡ 走的接口）

```bash
curl -X POST http://<SERVER_IP>:5081/api/import/batch \
  -H 'Content-Type: application/json' \
  -d '{
    "links": ["magnet:?xt=urn:btih:xxxx", "ed2k://|file|示例.avi|123456|yyyy|"],
    "kind": "fanhao",
    "category": "av",
    "thread_id": "1234567",
    "title": "【原档】示例标题",
    "thread_url": "https://sehuatang.net/thread-1234567-1-1.html",
    "dry_run": true
  }'
```

- `dry_run: true` 只回解析结果（`items` / `errors`），不建任务 —— 用于自检与面板预览
- `thread_id` 缺省时会从 `thread_url` 里抠 `thread-<id>` / `tid=<id>`，保证落点与单条入库一致
- 链接行尾可写 `#sw` 之类单独覆盖 `category`；同一链接重复出现会被记进 `errors` 并计为 `skipped`

### 示例：元数据补充

```bash
curl -X POST http://<SERVER_IP>:5081/api/metadata \
  -H 'Content-Type: application/json' \
  -d '{
    "thread_id": "1234567",
    "title": "示例标题",
    "desc": "帖子简介",
    "kind": "fanhao",
    "images": [{"name":"poster.jpg","data":"<base64>"}, ...]
  }'
```

## 四、播放

| 入口 | 地址 | 说明 |
|---|---|---|
| Emby 管理 | `http://<SERVER_IP>:8096` | Web 界面 |
| 播放地址 | `http://<SERVER_IP>:8097` | 客户端（网易爆米花/VidHub 等）填这个地址 |

> 播放走 302 直链：客户端请求 → 8097 → SmartStrm 302 → 115 CDN 直连。视频流不占服务器带宽。

## 五、日常运维速查

```bash
# 重启入库服务
systemctl restart import-api

# 查看入库日志
journalctl -u import-api -f

# 查看限频状态（云主机）
cat /opt/115push/ratelimit_state.json

# SmartStrm 容器
docker logs smartstrm --tail 50
```
