# 「无码」分类（2026-10-21）

## 起因

用户要在批次入库弹层的分类下拉里**直接选「无码」**，让无码片进 Emby 的「无码」库，不跟有码 AV 混在一起找。

> 关键概念：**Emby 媒体库名单 ≠ 分类下拉名单**。下拉全部来自 `import_api.CATEGORY_MAP`（唯一真源），
> 前端页面是请求时注入的（`const CATS = ...`），加一行后端就多一项，前端不用改。
