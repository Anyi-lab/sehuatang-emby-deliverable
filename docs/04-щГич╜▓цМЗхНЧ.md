# 04 · 部署指南

---

## 一、服务器要求

| 项 | 要求 | 说明 |
|---|---|---|
| 系统 | Linux + Docker | Ubuntu/Debian 均可 |
| 内存 | ≥4GB（推荐 8GB） | 2GB 会被 Emby 转码压垮（swap 满载） |
| 带宽 | ≥5Mbps | 302 直链不占服务器带宽，主要用于管理操作 |
| 磁盘 | strm 目录很小（文本） | nfo/图片本地存储，几百 MB 足够 |
| 外网 | 公网 IP 或端口映射 | 5081/8097/8096/8024 需要可达 |

## 二、部署步骤

### 2.1 目录规划

```
/opt/media/
├── smartstrm/config/        # SmartStrm 配置
├── strm/                    # strm 文件根目录
│   ├── emby/                #   电影 strm（Emby 挂载 /media/strm）
│   └── tv/                  #   剧集 strm
├── strm-nginx/              # nginx 反代配置
├── emby/config/             # Emby 配置
└── clouddrive2/             # CD2 配置与挂载点

/opt/115push/                # import-api 代码目录
├── import_api.py
├── monitor_ratelimit2.py
├── fs115.py / cd2grpc.py
├── import_log.db            # 任务记录（SQLite，自动创建）
├── cookies.json / creds.json / qr_token.json   # 115 凭证（自动生成）
└── ratelimit_state.json     # 限频状态（自动生成）
```

### 2.2 部署容器

参考 `configs/docker-compose.example.yml`：

```bash
cp configs/docker-compose.example.yml /opt/media/docker-compose.yml
cd /opt/media && docker compose up -d
```

容器清单：
- **clouddrive2**：115 挂载 + 离线下载（gRPC 19798）；首次启动后需在 Web 界面登录 115
- **smartstrm**：核心（8024 管理 / 8098 302 代理）；首次需扫码授权 115 + 填 Pro license
- **strm-nginx**：8097 播放入口
- **emby**：8096 媒体库
- **mdc**：MDCng 刮削器

### 2.3 配置 SmartStrm

1. 将 `configs/smartstrm-config.example.yaml` 中所有 `<...>` 占位符替换为实际值
2. 放入 `/opt/media/smartstrm/config/config.yaml`，重启容器
3. 关键配置：
   - `license`：Pro 授权（302 代理必需）
   - `proxy.enabled: true`：**必须保持 true**，否则 8098 代理端口不启动、播放全部 502
   - `copy_ext: [nfo, ass, srt]`：不要含 jpg/png（避免复制 115 预览图触发风控）
   - `emby_delete_sync`：删除联动（慎开，删 Emby 条目会联动删 115 目录）

### 2.4 部署 import-api

```bash
mkdir -p /opt/115push
# 上传 src/server/*.py 到 /opt/115push/
# 安装依赖
pip install grpcio p115client
# 注册 systemd 服务
cp configs/import-api.service /etc/systemd/system/
systemctl daemon-reload && systemctl enable --now import-api
```

配置项（环境变量）：
| 变量 | 默认 | 说明 |
|---|---|---|
| `IMPORT_MAX_CONCURRENT` | 1 | 串行队列并发数（建议 1） |
| `META_UPLOAD_115` | 0 | 1=元数据上传 115（旧行为）；0=直写本地（推荐） |

### 2.5 配置播放反代

将 `configs/strm-nginx.conf` 放入容器，`server_name` 改为你的域名/IP。

### 2.6 防火墙

| 端口 | 用途 | 暴露范围 |
|---|---|---|
| 5081 | 入库 API | 建议 IP 白名单（敏感操作） |
| 8097 | 播放入口 | 公网 |
| 8096 | Emby 管理 | 按需 |
| 8024 | SmartStrm 管理 | 不建议公网 |

## 三、初始化配置清单

首次使用前准备：

1. **115 VIP 账号**（离线下载功能必需）
2. SmartStrm 中扫码授权 115（生成 token，绑定实例，约 2h 滚动刷新）
3. CD2 中登录 115（生成挂载 `115open`）
4. Emby 添加媒体库：
   - 电影库：`/media/strm/emby`
   - 剧集库：`/media/strm/tv/emby_tv`
   - 开启 nfo 本地读取器
5. Emby 生成 API Key，填入 `import_api.py` 的 `EMBY_TOKEN`（占位符替换）
6. SmartStrm 生成 webhook token，填入 import-api 的 `SMARTSTRM_WEBHOOK`
7. 浏览器安装油猴脚本并配置 `API_BASE`

## 五、常见问题

### 5.1 播放 502 / 连不上
- 检查 SmartStrm `proxy.enabled` 是否为 `true`（false 时 8098 不监听）
- 检查容器：`docker ps`、`docker logs smartstrm --tail 50`
- 检查 8097 nginx 是否把请求转发到 smartstrm:8098

### 5.2 115 限频（错误码 770004）
- 停止批量操作，等限频窗口（约 180s）自动恢复
- `monitor_ratelimit2.py` 会自动检测并恢复，也可手动重启
- 规避：推送限速 ≥3s/条、批量 ≤10/批、避免全量扫描

### 5.3 任务卡在 wait（等待文件落地）
- 115 离线任务可能失败（种子无源），等 `wait_video` 超时后标记失败
- 检查 CD2 离线任务状态

### 5.4 MDC 刮削失败
- 文件命名不规范 → 入库流程已含「按番号重命名」环节，可在任务页点 🎬MDC 重跑
- 仍失败 → 用油猴 📤 手动补充元数据

### 5.5 Emby 条目标题显示为 thread_xxx
- 原因：条目创建时锁定了目录名，Refresh 无效
- 处理：删除异常条目（**必须先临时禁用两个删除联动**，否则会联动删 115 目录）→ 触发 Emby 扫库重建 → 或点 🎬MDC 重跑

## 六、安全建议

1. 5081 入库 API 可执行 115 推送/删除等敏感操作，**严禁无鉴权暴露公网**（建议内网或 IP 白名单）
2. 8024 SmartStrm 管理页不要暴露公网
3. 115 凭证（token/cookie）绑定实例且敏感，不要跨实例复制
4. 定期备份 `import_log.db` 与 SmartStrm config
