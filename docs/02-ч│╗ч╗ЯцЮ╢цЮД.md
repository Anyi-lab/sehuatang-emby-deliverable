## 二、组件清单

| 组件 | 端口 | 作用 |
|---|---|---|
| **import-api**（`import_api.py`） | 5081 | 入库核心 API：接收油猴请求、串行任务队列、推 115、等落地、触发 strm、调度刮削、状态监控页 |
| **SmartStrm** | 8024 / 8098 | 增量扫描 115 生成 strm；302 直链代理（Pro）；Emby 删除联动 webhook |
| **strm-nginx** | 8097 | 播放唯一入口：反代到 SmartStrm 8098，注入 `X-Forwarded-Proto` |
| **Emby** | 8096 | 媒体库（电影库 + 剧集库），扫库 strm 目录 |
| **CloudDrive2 (CD2)** | 19798 | 115 挂载 + 离线下载 gRPC；import-api 的所有 115 操作走 CD2 |
| **MDCng** | 内部 | 番号影片自动刮削（watch strm 目录 → nfo/图片） |
| **monitor_ratelimit2** | — | 限频监控（770004）→ 暂停队列 → 自动恢复 |

## 三、数据流（入库主流程）

```
油猴脚本 /api/import 提交 {thread_id, title, magnet|ed2k, kind, thread_url}
  → 队列（限频感知：限频中提示等待）
  → 串行 worker：
      1. 推送磁力到 115 离线下载（先建 /sehuatang/thread_<id> 目录）
      2. 等待文件落地（轮询 CD2 离线任务状态）
      3. 落地检查（无视频 → 失败标记）
      4. 影片(fanhao)：MDCng 自动刮削 nfo/图片
         剧集(non_fanhao)：重命名 thread_<id>_S01E01.. → 等油猴补充元数据
      5. 触发 SmartStrm webhook → 增量生成 strm
      6. Emby 刷新 → 预热播放地址
```

## 四、数据流（播放链路）

```
客户端 → http://<SERVER_IP>:8097/emby/...（strm-nginx）
       → smartstrm:8098（302 代理，按 UA/客户端分流）
       → 302 → 115 CDN（cdnfhnfile.115cdn.net）→ 206 直连播放

关键：视频流全程 302 到 115 CDN，不经过 Emby/服务器中转
```

## 五、目录约定

| 路径（115） | 路径（本地） | 说明 |
|---|---|---|
| `/sehuatang/thread_<id>/` | `/strm/emby/thread_<id>/` | 影片（番号）目录 |
| `/sehuatang_tv/thread_<id>/` | `/strm/tv/emby_tv/thread_<id>/` | 剧集目录（strm 命名 `{集标题}.thread_<id>.S01E01.(mp4).strm`） |

## 六、关键设计决策

1. **strm 规避风控**：Emby 扫库只读 strm 文本，不触发 115 接口
2. **115 只存视频**：元数据（nfo/图片）默认直写本地，不上传 115（`META_UPLOAD_115=0`）
3. **目录按 thread_id 命名**：与帖子一一对应，`/api/metadata` 匹配目录优先精确匹配 `thread_<tid>`
4. **串行队列**：`IMPORT_MAX_CONCURRENT=1`，避免密集操作触发 770004
5. **限频闭环**：监控器发现 770004 → 全局暂停 → 冷却探测 → 恢复后自动重试失败任务
6. **浏览器端刮削**：服务器不做网页抓取（云主机无浏览器/反爬），由油猴从帖子页抓标题/简介/图片
