# 01 · 项目概述

> 2026 年 7 月启动 · 历经两代部署形态（家宽 → 云主机）· 全链路自动化打通

---

## 一、背景与目标

在论坛（色花堂）上，资源以磁力/ed2k 链接形式发布。传统做法是：手动复制链接 → 下载 → 整理命名 → 刮削元数据 → 入库媒体库 → 供多设备播放。

**本项目目标**：把这套流程完全自动化——

1. **播放源 = 115 网盘**：视频文件存储于 115 离线下载，本地只保留 strm 指针文件（几 KB 文本），规避 115 扫描风控
2. **外网可播放**：通过 302 直链，客户端直接连 115 CDN，视频流不经过媒体服务器
3. **全链路自动化**：浏览器油猴脚本 → 入库 API → 115 离线下载 → strm 生成 → 刮削 → Emby 入库 → 播放

---

## 二、技术选型

| 环节 | 选型 | 理由 |
|---|---|---|
| 论坛抓取 | 油猴脚本（Tampermonkey） | 直接在帖子页操作，天然通过登录态；无需爬虫反爬 |
| 存储 | 115 网盘（离线下载） | 大容量（TB 级），磁力秒下 |
| 文件系统桥 | CloudDrive2（CD2） | 把 115 挂载为文件系统；gRPC 接口做离线下载/列目录，避免 FUSE 缓存不一致 |
| strm 生成/302 代理 | SmartStrm（Pro） | 核心组件：增量扫描 115 → 生成 strm；302 直链代理（Pro 功能） |
| 媒体库 | Emby（amilys 镜像） | 成熟媒体服务器，支持 strm、多客户端 |
| 刮削 | MDCng + 浏览器端补充 | 番号影片自动刮削；剧集/失败任务由油猴从帖子页补充元数据 |
| 入库 API | import_api.py（Python 单文件） | 串行任务队列 + 限频感知 + 状态监控页面 |

## 三、演进历程

### 阶段 1（7 月）：方案调研
对比 SmartStrm / alist+SmartStrm / QMediaSync 三套方案，选定 **SmartStrm（Pro）+ Emby**（302 代理是 Pro 付费功能）。

### 阶段 2：115 离线推送打通
关键结论：
- SmartStrm 的 open token 只能用于文件接口；**添加离线任务必须用网页 cookie（扫码登录）**
- 115 的 savepath 不自动创建目录 → 推送前必须先建 `/sehuatang/thread_<id>` 目录拿 fid

### 阶段 3：刮削器
浏览器过 Cloudflare 抓主题页 → 生成 nfo + poster + fanart。踩坑：文件无扩展名需自动 rename、p115client 上传 bug 修复、磁力包自带子文件夹递归遍历。

### 阶段 4：播放链路打通（核心）
- 302 链路：客户端 → strm-nginx(8097) → SmartStrm(8098) → 302 → 115 CDN 直连播放
- **TLS 指纹问题**：115 CDN 按 JA3 指纹过滤，Emby 内置 ffmpeg（mbedtls）被拒 → 用 BtbN OpenSSL TLS 静态 ffmpeg 替换（patchelf DT_RPATH）
- **X-Forwarded-Proto 问题**：HTTPS 反代不传该头会导致 SmartStrm 生成 http 播放地址 → strm-nginx 注入修复

### 阶段 5（8 月）：云主机迁移
家宽网络不稳定（公网 IP 变化、穿透不稳定）→ 整体迁移到云主机：
- 存量 strm 不迁，SmartStrm 在云主机重扫 115 重新生成
- 部署 SmartStrm + strm-nginx + Emby + CD2 + MDCng + import-api
- **完全去 MySQL**：爬虫库不再参与入库流程，所需字段全部由油猴脚本从网页端提交（thread_id/title/thread_url/magnet/kind）

### 阶段 6：工程化加固
- **115 限频闭环**：monitor_ratelimit2 监控 770004 → 暂停队列 → 探测恢复 → 自动 resume 失败任务
- **MDC 重跑按钮**：任务监控页一键重跑（从 115 源文件重建 strm + 刮削）
- **影片重命名环节**：入库时按番号重命名 115 文件，提升 MDC 刮削成功率
- **Emby 转码并发限制 =1**：小内存机器防多客户端同时转码压垮

## 四、当前成果

- 影片（番号）与剧集（非番号）双流程稳定入库
- 播放链路：网页版 / 网易爆米花 / VidHub / SenPlayer 实测可用
- 任务监控页：状态列表、详情、MDC 重跑、帖子跳转、元数据补充一站式
- 已入库媒体数百部，日增量自动化运行

## 五、局限与注意

1. **115 风控**：批量操作必须限速（推送 ≥3s/条、≤10/批）；监控 770004 并自动退避
2. **Emby 删除联动危险**：删除 Emby 条目会联动删除整个 115 目录（StrmDeleteSync），操作前务必确认
3. **凭证生命周期**：115 token 绑定实例、约 2h 滚动刷新、不可跨实例复制；迁移后需重新扫码授权
4. **小内存机器**：Emby 软转码（HEVC）可能拖垮整机，建议限制转码并发
