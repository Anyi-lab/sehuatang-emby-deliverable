# 06 · 入库自动分类（avdb 下载 → 归属分类）— 2026-09-27

## 问题

订阅（演员 / 合集 / 排行榜）拉回来的片子是混合的：有码、无码、欧美、FC2、国产、里番 都有，
但入库侧连接器 `avdb_watch.py` 的分类是**启动参数里的固定值**（`AVDB_WATCH_CATEGORY=av`），
于是一律按 AV 入库，欧美/FC2 全混进 AV，只能事后手工搬。

## 根因（代码 + 数据取证，2026-09-27）

1. **排行榜订阅不保留来源分区。**
   `app/api/services/subscription_service.py:7841` 用
   `for period in config["periods"]: for content_type in config["content_types"]:`
   拉 JavDB 榜单（`content_types` 的 0/1/2/3 = 有码/无码/欧美/FC2），
   但抓到的影片被合并进同一个 `movies` 列表，创建订阅时只写
   `movie_id / number / title / cover_url / release_date + 默认规则`，`source='javdb_ranking'`。
   → **「这条是哪张榜来的」在落库时就丢了**。

2. **订阅下载的目录解析不出 section/category。**
   默认规则里 `save_path = "{section}/{category}"`。帖子（文章）下载时这两个值来自论坛版块和主题分类，
   所以能落地成 `亚洲无码/无码破解`；而订阅走
   `_resolve_subscription_save_path()`（`subscription_service.py:5166`）只解析
   `{publish_date}`，section/category 落到兜底值 → **全部进 `未分区/未分类`**。
   `download_log` 全量 333 条里 327 条就是这样。

3. **分类信息其实在 avdb 库里就有。**
   `article` 表存着帖子的 `section`(版块) + `category`(主题分类)，这是发帖人手工选好的。
   实测版块分布：亚洲有码 96226 / 国内成人 78786 / 亚洲无码 56272 / 中文字幕 44931 /
   三级写真 19843 / 欧美无码 15327 / 素人有码 7724 / VR视频区 5281 / 4K原版 5114 /
   动漫原创 998 / FC2 712 / 韩国主播 163 / MGS 142。
   其中 `亚洲无码/FC2PPV` 20926 条、`欧美无码` 15323 条 —— FC2 和欧美 是可判的。

## 方案

新增 `src/server/avdb_classify.py`：给每条 download_log 记录判一个入库分类（av/fc2/sw/cn/ea/lf）。

判定优先级（先准后糙）：

| 级 | 依据 | 规则 | 置信 |
|---|---|---|---|
| 1 | article 回查（按 tid，再按 number） | `category` 含 FC2PPV / FC2 → **fc2**；`category` 含 欧美 → **ea**；section=FC2 → **fc2**；欧美无码 → **ea**；国内成人 / 韩国主播 → **cn**；动漫原创 → **lf**；三级写真+美国三级/四级 → **ea**；其余 AV 版块（亚洲有码/亚洲无码/素人有码/中文字幕/4K原版/VR视频区/MGS）→ **av** | high |
| 2 | 番号 | `FC2-PPV-xxxx` / `FC2PPVxxxx` → **fc2**；纯 6–7 位数字 → **fc2**(mid)；欧美式编号 → **ea** | high/mid |
| 3 | 标题 | 命中欧美厂牌（brazzers/tushy/vixen/blacked/…）→ **ea**；`--with-sw` 时命中丝袜关键词 → **sw** | high/mid |
| 4 | 标题语言 | 无番号 + 标题近乎全西文 → **ea** | low |
| 5 | 兜底 | **av** | low |

`avdb_watch.py` 已接上：`--category auto` 时逐条判定（默认仍是 `av`，行为不变可回退），
提交时把 `cat=xx(理由)` 写进台账 `note`，日志同打。新增 `--explain <番号>` 看判定依据。

## 验收（2026-09-27 实测）

* 拿 article 表各版块真实帖子抽样（每类 15 条）跑分类：**8/8 版块组合全对** ——
  亚洲无码/FC2PPV→FC2、FC2 版块→FC2、欧美无码→欧美、国内成人/国产无码→国产自拍、
  动漫原创→里番、亚洲有码→AV、亚洲无码/无码破解→AV、三级写真/美国三级→欧美。
* 去掉帖子元数据（模拟纯订阅）只给番号+标题：FC2PPV 14/15→FC2、FC2-PPV 15/15→FC2、
  欧美无码 15/15→欧美；**国产自拍 / 里番 兜不住**（番号形状与 JAV 有码一模一样，必须靠帖子回查）。
* 历史 333 条 download_log 全量跑一遍：274 条有帖子元数据（82%，全部判 AV，符合"这批都是演员订阅的有码片"）；
  59 条无元数据的落到默认 AV（抽样放宽匹配只能救回 6 条，且也都是 亚洲有码 → AV，不值得为此加复杂度）。

   无码（破解/无修正）默认进 AV，靠 MDCng 刮削角标体现；要单开需新增 CATEGORY_MAP + MDCng watch + Emby 库。
